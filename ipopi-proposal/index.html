03 · KEY FLOWS · 业务闭环

三条闭环，
决定一个商城能不能跑起来。

FLOW A

购买闭环

P01–P08 · P13–P14
首页 / 分类 / 搜索 → 详情选规格 → 购物车 → 确认订单 → 支付 → 物流 → 收货 → 评价
重点：库存与价格下单前复核、支付以服务端结果为准。
FLOW B

售后闭环

P13 · P15
订单详情 → 选商品 → 类型与原因 → 凭证 → 审核 → 退货 / 退款 → 结果
重点：可退金额不超上限，退款走原渠道不重复。
FLOW C

会员闭环

P10 · P16 · P17
注册登录 → 会员中心 → 等级与权益 → 签到 / 积分 → 兑换优惠券 → 结算使用
重点：签到、兑券幂等，积分扣减与发券同时成功。
IA · 信息架构手机端底部导航：首页 · 分类 · 会员 · 购物车 · 我的，消息入口在顶部；电脑端改为顶部横向导航 + 个人中心侧栏，不照搬手机底部导航。
