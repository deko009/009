# 06-open: launch day EDM (Oct 13)

A redesign of the "06-open" launch email, built with the Ronini supporting graphics.

- `index.html`: a 600px table-based email with inline styles. It stacks to a single column below 620px.
- `assets/`: walking character (hero), gradient characters strip, R character with legs, bubble "ronini" wordmark, all exported at 2x.
- Cream base (`#F5F2EA`); the sizes block borrows the slide style: periwinkle gradient panel, orange-gradient arch cards with a navy outline.

Placeholders to fill in the ESP: `[[SHOP_URL]]`, `[[RETURNS_URL]]`, `[[PRODUCT_IMAGE_URL]]`, `[[HOME_URL]]`,
`[[INSTAGRAM_URL]]`, `[[PREFERENCES_URL]]`, `[[UNSUBSCRIBE_URL]]`. Upload `assets/` to the ESP or CDN and swap the
relative `assets/...` paths for the hosted URLs.

Palette: navy `#2C0D57`, orange `#F34D0D`, periwinkle `#7084F4`, sky `#C6D6F7`, cream `#F5F2EA`, paper `#FFFCF6`.
