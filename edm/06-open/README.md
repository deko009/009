# 06-open: launch day EDM (Oct 13)

`index.html` mirrors the Figma frame "LAUNCH · 06-open-to-everyone · REDESIGN" (cream version)
on the EDM page of Ronini Website Design Prototype (P0).

- 600px table-based email, inline styles, stacks below 620px.
- Copy blocks are marked with `<!-- COPY: ... -->` comments for quick edits.
- Fonts: Parkinsans SemiBold (headlines) and Onest (body), with Helvetica/Arial fallback.
- `assets/`: logo, walking character, character band (exported from Figma) and the Instagram icon, all at 2x.

Placeholders to fill in the ESP: `[[SHOP_URL]]`, `[[RETURNS_URL]]`, `[[PRODUCT_IMAGE_URL]]`, `[[HOME_URL]]`,
`[[INSTAGRAM_URL]]`, `[[PREFERENCES_URL]]`, `[[UNSUBSCRIBE_URL]]`. Upload `assets/` to the ESP or CDN and swap the
relative `assets/...` paths for the hosted URLs.
