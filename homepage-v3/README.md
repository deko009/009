# VALTINSU 首页设计稿 v3（HTML 高保真）

按《首页文案 v3》的 6 个内容模块做的首页设计，文案逐字取自 v3 Word。双击 `index.html` 用浏览器打开即可，不需要联网（字体已放在本地）。

- 右下角蓝色按钮「显示标注」：显示模块编号（与文案 Word 的 00–09 对应）、照片位说明，蓝色虚线框 = 等客户确认的内容。链接加 `?notes=1` 默认打开标注。
- 响应式：1440 桌面 / 768 平板 / 390 手机，拖动浏览器宽度即可看。手机端底部有 WhatsApp + 获取报价固定栏。

## 风格

客户喜欢的参考是 E Ride Pro 和 Sur-Ron USA，所以：

| 项 | 做法 |
|---|---|
| 颜色 | 深蓝 #160E23 + 米白 #F9F4EC 为底；橙 #FB5011 只给主按钮、新品标和询盘区；蓝 #006AFF 只用于标注和键盘焦点 |
| 字体 | Archivo 宽体（标题）；型号名用 Archivo 斜体加宽，跟 logo 的斜体字一致；IBM Plex Mono 用于参数和小标签 |
| 版式 | 直角、细线分隔，不用圆角卡片、阴影卡片、渐变和图标 |
| EM-5 模块 | 参考 E Ride Pro：点型号即时切换大图和参数；参数同时给 km/h 和 mph，方便美国经销商 |
| 产品线 | 电动、燃油两张同尺寸大图卡，地位相同 |

## 文件

- `styles.css` 样式（顶部 `:root` 是颜色、字体、间距变量，开发可直接沿用）
