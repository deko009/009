# 小红书 ins 风帖子流水线

## 1. 剪贴素材
运行 `python -m xhs.clip <网址> --name <素材名>`，产出 `materials/<素材名>/`：
`images/`（原图）、`material.json`（标题、段落、图片来源）、`screenshot.png`（整页截图）。
读 `material.json` 挑出最适合做封面和内页的图片。

## 2. 放进 Figma 排版
用 Figma 连接器在用户指定的文件里新建一个 Frame 组：
- 尺寸：3:4 竖图 1242×1656（小红书推荐）
- 第 1 张是封面，其余是内页
- 把挑选的素材图放进去，按下面的「风格规则」排版
完成后把每个 Frame 导出 PNG 到 `posts/<帖子名>/1.png, 2.png ...`

## 3. 写文案
在 `posts/<帖子名>/post.json` 写入 `account`、`title`（≤20 字）、`body`（≤1000 字）、`tags`。
按下面的「文案规则」写。

## 4. 发布
- 单篇：`python -m xhs.publish post posts/<帖子名>`（填好后由用户确认发布）
- 队列：`python -m xhs.publish run`（每篇间隔 20–60 分钟随机）
发布在用户自己电脑上运行；云端会话只负责准备素材、Figma 和 post.json。
